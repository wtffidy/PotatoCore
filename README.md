# PotatoCore

**A configurable automation toolkit for Minecraft 1.20.1 / Forge 47.4.28.**

PotatoCore is a client-side utility mod focused on reusable automation profiles and an in-game macro builder.

## Target environment

- Minecraft: `1.20.1`
- Forge: `47.4.28`
- Java: `17`
- Project Infinity pack: `0.1` (manifest version `0.0.52.1` supplied during setup)

## Current implementation

The initial repository migration includes a configurable click automation engine and the first Macro Builder profile for the Blood Magic Sacrificial Knife.

See the source tree and subsequent commits for implementation details and current integration status.
